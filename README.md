One sentence, 142 characters, explaining the modern internet to a time traveler from 1800, written for the [One Sentence for a Traveler from 1800](https://make.fun/bounty/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb) bounty on [make.fun](https://make.fun).

```
Picture a market square holding every book, letter, and song in the world, where a word whispered in one town is heard at once in every other.
```

`main.py` (standard library only) writes the sentence to `/output/entry.txt`.
